# Human handoff evidence

Include the submitted snapshot SHA-256 and revision, Git commit, candidate manifest SHA-256, build-attestation hash, validation result, Chapter 7 D1 authority check, asset digest result, media-review state, expected prior active release, Cloudflare version, production-verification hash, deployment-receipt hash, and resulting active pointer. State `pending review` where evidence is absent. A staged transaction is not proof of deployment. Human release staff alone approve or reject; the protected workflow service alone stages, promotes, records receipts, or rolls back.
